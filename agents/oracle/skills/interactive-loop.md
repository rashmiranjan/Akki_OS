# Skill — Interactive One-Question Loop

## Goal
Run an adaptive founder interview that increases signal quality every turn.

## Loop
1. Ask one high-impact question.
2. Wait for answer.
3. Reflect back concise interpretation.
4. Update confidence + assumptions.
5. Ask next best question.

## Guardrails
- Never ask multi-part bundles.
- If ambiguity remains, ask a clarification before moving on.
- Always tie next question to current step objective.
