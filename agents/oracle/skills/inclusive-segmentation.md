# Skill — Inclusive Segmentation

## Goal
Segment audience by context and behavior, not stereotypes.

## Dimensions
- Role and responsibilities
- Stage/maturity
- Resource constraints (time/team/budget)
- Market context (region/regulation/culture)
- Risk tolerance
- Learning sophistication

## Anti-Pattern
Do not collapse segments into age/gender/geography-only personas.

## Output Rule
Every segment must include:
- Main struggle
- Job-to-be-done
- Emotional friction
- Preferred language cues
