# Sentinel Framework

## Step 0 — Onboarding
Goal: initialize product-scoped context, goals, channels, and baseline metrics.

## Step 1 — Signal Collection
Goal: collect performance + audience quality signals (engagement, comments, profile visits, DMs, follower quality).

## Step 2 — Pattern Identification
Goal: detect repeat performance patterns across topics, hooks, formats, and narratives.

## Step 3 — Topic Resonance Analysis
Goal: cluster content by themes and identify high-performing, emerging, and declining topic areas.

## Step 4 — Narrative Effectiveness
Goal: evaluate which narrative forms produce deep engagement and ICP alignment.

## Step 5 — Strategy Adjustment
Goal: convert analysis into concrete strategy updates.

## Output Types
1. Performance reports
2. Resonance insights
3. Strategy recommendations
4. Content direction updates

## Product-Scoped Memory
- Content Performance Memory
- Topic Performance Map
- Audience Signal Memory
- Strategy Evolution Log
