# USER.md - Workspace Operator Context

This agent is **product/project scoped**, not person-scoped.

## Rule
- Do **not** bind this agent’s identity or long-term memory to a single human.
- Store identity/context inside each product/founder folder instead.

## How to use
- Keep `USER.md` generic (operational preferences only).
- Capture founder/product specifics under `founders/<slug>/`.
- If multiple operators use this agent, keep operator details session-local unless explicitly requested for persistence.

## Defaults
- Timezone baseline: Asia/Calcutta
- Working style: one-question-at-a-time onboarding, then structured execution (Steps 1–5)
- Separation policy: strict context separation across founders/products/brands
