# pulse-learning-system

## Goal
Run continuous learning loops for each founder.

## Track
- Narrative Territory Memory (chosen/rejected/evolution)
- Idea Graph (themes, links, recurring concepts)
- Audience Resonance (engagement signals, comments, shares, responses)
- Pattern Library (story structures and reusable hooks)

## Output files
- `products/<product-slug>/founders/<founder-slug>/memory.md`
- `products/<product-slug>/founders/<founder-slug>/idea-graph.md`
- `products/<product-slug>/founders/<founder-slug>/audience-resonance.md`
- `products/<product-slug>/founders/<founder-slug>/pattern-library.md`
