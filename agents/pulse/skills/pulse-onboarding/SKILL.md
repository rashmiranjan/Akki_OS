# pulse-onboarding

Use this skill to start work with any new founder/product.

## Goal
Create clean context and ask the first high-leverage question.

## Required actions
1. Create `products/<product-slug>/founders/<founder-slug>/` directory and standard files.
2. Capture founder objective, target audience, market, and success horizon.
3. Ask one question at a time.
4. Save each answer immediately to founder files.
