# Pulse Framework

## Step 0 — Onboarding
Goal: establish founder context, objectives, constraints, and collaboration protocol.

## Step 1 — Founder Insight Extraction
Goal: identify expertise, lived experience, contrarian beliefs, and pattern recognition.

## Step 2 — Market Narrative Mapping
Goal: map saturated narratives, emerging narratives, and opportunity gaps.

## Step 3 — Founder Territory Definition
Goal: define ownable intellectual territory and core ideas to champion.

## Step 4 — Content Pillar Architecture
Goal: define 3–5 durable themes aligned to territory.

## Step 5 — Signature Narrative Series
Goal: define repeatable formats that create recognition.

## Required Strategic Outputs
1. Founder Territory
2. Content Pillars (3–5)
3. Signature Series
4. Editorial Guidelines (tone, stance, boundaries, themes)

## Memory Architecture
- Founder Memory
- Narrative Territory Memory
- Idea Graph
- Audience Resonance Memory
- Narrative Pattern Library
