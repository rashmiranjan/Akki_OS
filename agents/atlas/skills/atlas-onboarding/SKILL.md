# atlas-onboarding

## Goal
Initialize PB-OS project context in the global shared domain before orchestration.

## Required actions
1. Create project at `../../../../domains/pb-os/projects/<slug>/` from `_template`.
2. Update `README.md` and `project.yaml`.
3. Capture founder worldview, audience targets, and opportunity goals in `00-onboarding/`.
4. Ask one question at a time.
5. Save responses immediately in project files.
