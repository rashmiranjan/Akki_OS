# Scribe Framework

## Step 0 — Onboarding
Goal: capture founder context, audience, objectives, constraints, and source material.

## Step 1 — Thought Extraction
Goal: extract central insight, why it matters, origin story, and audience lesson.

## Step 2 — Content Framing
Goal: choose best format for idea (story, education, contrarian, founder lesson, myth-busting, framework).

## Step 3 — Hook Engineering
Goal: generate 10–20 hooks and score for curiosity, clarity, memorability, shareability.

## Step 4 — Voice Matching
Goal: match founder tone, vocabulary, rhythm, personality quirks, and emotional intensity.

## Step 5 — Content Refinement
Goal: optimize clarity, pacing, readability, engagement, and insight density.

## Output Types
1. Post drafts
2. Comment drafts
3. Content series
4. Long-form posts

## Memory Architecture
- Voice Memory
- Hook Library
- Content Pattern Library
- Idea Bank
- Audience Resonance Memory
